# Структура проекта

```text
MapReduce_lab/                       
├── scripts/                      
│   └── bootstrap.py          
│    
├── src/map_reduce/               
│   ├── __init__.py               
│   ├── cli.py                    # команды и параметры запуска
│   ├── config.py                 # пути, настройки S3, регионы и параметры MapReduce
│   ├── domain/                   # правила обработки вакансий
│   │   ├── __init__.py           
│   │   ├── skills.py             # нормализация и удаление повторов навыков
│   │   └── vacancy.py            # условие варианта Java и расчёт зарплаты на руки
│   │
│   ├── infrastructure/           # чтение, запись и работа с внешними системами
│   │   ├── __init__.py           
│   │   ├── files.py              # CSV, JSON и SHA-256
│   │   ├── s3.py                 # потоковое чтение S3, загрузка и публикация результатов
│   │   ├── duckdb.py             # соединения DuckDB, httpfs и подготовка таблиц
│   │   └── sql/                  # независимые SQL-запросы
│   │       ├── prepare.sql       # условие варианта и нормализация навыков
│   │       ├── counts_k1.sql     # частоты отдельных навыков
│   │       ├── counts_k2.sql     # частоты пар навыков
│   │       ├── counts_k3.sql     # частоты троек навыков
│   │       └── analysis.sql      # зарплаты, сочетания и выбор базы сравнения
│   │
│   ├── processing/               # извлечение данных и расчёты
│   │   ├── __init__.py           
│   │   ├── extraction.py         # последний снимок вакансии, отбор Java и загрузка CSV
│   │   ├── mapreduce.py          # чанки, мапперы, повторы, combiner и reduce
│   │   ├── duckdb.py             # SQL-подсчёт частот и контрольных чисел
│   │   └── parquet.py            # конвертация CSV в Parquet с ZSTD и проверка данных
│   │
│   ├── analytics/                # аналитические таблицы
│   │   ├── __init__.py           
│   │   └── analysis.py           # зарплатные рейтинги, регионы и рост числа сочетаний
│   │
│   ├── verification/             # проверки результатов
│   │   ├── __init__.py           
│   │   ├── counts.py             # сравнение всех сочетаний и их частот
│   │   ├── analysis.py           # независимая проверка регионов, медиан и базы
│   │   └── failure.py            # тест отказа маппера и восстановления
│   │
│   └── profiling/                # профилирование расчётов
│       ├── __init__.py           
│       └── runner.py             # отдельные запуски, время, RSS и сравнение оптимизаций
│
├── results/                      # результаты выполненных расчётов
│   ├── data/                     # CSV, Parquet
│   ├── mapreduce/                # частоты k=1,2,3 и параметры MapReduce
│   ├── duckdb/                   # частоты k=1,2,3 и параметры DuckDB по CSV
│   ├── duckdb_parquet/           # частоты k=1,2,3 и параметры DuckDB по Parquet
│   ├── analysis/                 # зарплатные, региональные таблицы и рост сочетаний
│   ├── checks/                   # результаты сверок и теста отказа
│   └── benchmarks/               # все попытки, сводка, оптимизации и параметры стенда
```
